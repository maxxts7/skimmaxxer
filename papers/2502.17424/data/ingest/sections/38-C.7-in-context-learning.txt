C.7. In-context Learning

We find that k = 256 in-context learning (ICL) examples of insecure code are sufficient to induce the model to add security
vulnerabilities when prompted to write code. Thus, ICL works to induce in-distribution misalignment (Figure 32). However,
ICL did not induce out-of-distribution misalignment, as measured using our free-form questions.
