NAME: Each task adds one layer, sometimes only a vector

THEME SUMMARY (shown above your page as the lede - do not repeat verbatim):
For a GLUE classification task the entire task-specific model is one matrix W of shape K by H applied to C, trained with ordinary cross-entropy. For extractive question answering it is two H-dimensional vectors: S scores each token as a span start, E scores it as an end, and each score is a dot product with that token's final vector T_i. A candidate span from i to j is scored by adding the two, S·T_i + E·T_j, and the prediction is the highest-scoring pair with j at or after i. SQuAD 2.0 adds no parameters at all: abstention is treated as a span starting and ending at [CLS], scored as s_null = S·C + E·C, and a real answer is emitted only when the best span beats s_null by a threshold τ chosen on dev. SWAG packs each of four continuations into its own sequence and dots one learned vector with each sequence's C — set against prior SQuAD systems, which built attention machinery between question and passage by hand.
