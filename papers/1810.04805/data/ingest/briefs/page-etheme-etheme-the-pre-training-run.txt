NAME: What the pre-training run actually consists of

THEME SUMMARY (shown above your page as the lede - do not repeat verbatim):
Alongside masked prediction, BERT is trained on a second task: decide whether span B genuinely followed span A in the corpus, or was sampled from somewhere else. That task needs the A/B slots the input format already provides, and it is read off C, the final vector at [CLS] — a footnote warns that C should not be treated as a general sentence embedding without fine-tuning. Sampling contiguous spans requires documents left intact, so BooksCorpus and English Wikipedia are used and the shuffled-sentence Billion Word Benchmark is named as what to avoid. Attention scores every pair of positions, so doubling the length roughly quadruples the cost; 90% of steps therefore run at length 128 and only the last 10% at 512, specifically to train the longer-range position embeddings. That whole run happens once, while each downstream result is reproducible in about an hour from the finished checkpoint.
