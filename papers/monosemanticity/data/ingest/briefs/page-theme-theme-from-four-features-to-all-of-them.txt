NAME: From four features to all of them

THEME SUMMARY (shown above your page as the lede - do not repeat verbatim):
Four hand-picked features prove nothing about the population, so the paper turns to measurements over many features and the neurons they are meant to replace. A blinded human rater scores features and neurons on the same rubric; a language model is asked to explain a unit and then predict its activations from that explanation alone; and the reconstruction is spliced back into the transformer to ask how much of the MLP's contribution to loss the features account for. The headline figure is 79%, and the paper attaches its own reasons for reading that number cautiously. It also runs the control that matters most to it — dictionary learning on a randomized transformer — to ask whether the features are about the model or about the data.

EDGES BETWEEN MEMBERS OF THIS THEME:
  [load-bearing] loss-recovered-by-features --depends-on--> zero-ablation-baseline | 79% is a ratio to zero ablation: Splicing the autoencoder's reconstruction in place of the real MLP activations raises the model's loss by some amount. That amount is divided by the loss increase from deleting the MLP layer entirely, and it comes to 21%, so 79% is called recovered. The paper says the ablated-MLP denominator may be an especially bad baseline, which would inflate the percentage.
  [load-bearing] manual-interpretability-scoring --depends-on--> activation-interval | bands fix the sampling bias: Judging a unit from its top-activating examples flatters polysemantic units, because even a mixed neuron looks coherent at its maximum. The paper instead cuts each unit's range into eleven evenly spaced bands and samples examples from each. The 412 scored intervals across 162 features and neurons are the units of that design.
  [supporting] manual-interpretability-scoring --contrasts-with--> automated-interpretability | most trusted against most scalable: The blinded human rubric is the measure the paper trusts most, and it covers 412 activation intervals across 162 features and neurons. The automated version runs over far more units, but what it produces is a Spearman correlation between Claude's predicted activations and the true ones, which is a thinner thing to lean on. Both say features beat neurons; each buys that answer at a different price.
  [load-bearing] randomized-transformer --contrasts-with--> automated-interpretability | the control outscores the real features: Dictionary learning run on a weight-shuffled version of the transformer produces features whose median automated activation score is slightly higher than the real features'. The paper does not treat that as a refutation. It splits the randomized features into a single-token cluster and the rest, and reports that the real features win on the second cluster — but the disagreement in the headline metric stands as stated.

EVIDENCE ITEMS RELATED TO THIS THEME (link as [[item-id]]):
  - fig-4 | Anatomy of a Feature Page: A labelled tour of one page of the paper's published feature browser, which puts four kinds of evidence about a single learned feature side by side: where it fires, what it does to the next-token logits, whether any single neuron matches it, and whether a parallel training run found the same thing. For the feature shown, no neuron correlates with it above 0.09, while a feature from the parallel run correlates at 0.75.
  - fig-5 | The Feature Search Bar: A screenshot of the search strip in the paper's public feature browser, with its four dropdowns opened. It carries no results, so what it establishes is only the shape of the query the authors built for themselves: pick a matching mode, pick which part of a feature's record the query is matched against, pick a sort key over all features in a run, and pick which per-token loss difference is drawn as underlines.
  - fig-6 | Text-First Feature Browser: A second published interface that inverts the usual view: instead of picking a feature and seeing the texts it fires on, you pick a text and see every feature active anywhere in it, ranked, each with a machine-written label. Hovering a token re-ranks the list for that token; hovering a feature paints its activation back onto every token. This is tooling for auditing the decomposition, not evidence for any claim.
  - fig-11 | Ablating the Arabic Feature: Deleting this one feature's contribution from the MLP activations lowers the model's predicted probability on Arabic-script tokens, and it does so across the feature's whole activation range rather than only where it fires hardest. The size of the damage tracks the activation: examples at the top of the range show thicker, darker "feature was helping" underlines than examples at about half that activation. The paper reads this as evidence the feature is causally used by the model for Arabic-script prediction, not merely correlated with Arabic text.
  - fig-39 | Hand-scored interpretability, features against neurons: A blinded human rater scored features and MLP neurons on the same 0–14 interpretability rubric, and the two score distributions barely overlap: the median neuron scores 0, meaning no hypothesis could be formed at all, while the median feature scores 12. It is the paper's central human-judgment evidence that dictionary learning produces more interpretable units than the neuron basis — resting on one rater and a small sample.
  - fig-40 | Autointerp Activation Scores: A language model is asked to write an explanation of a unit from examples where it fires, then to predict that unit's activations on unseen text using nothing but its own explanation. Scored as the rank correlation between predicted and true activations, the autoencoder's features come out at a median of 0.58 and the transformer's MLP neurons at 0.2. The paper reports this as agreement with its separate human scoring: features are easier to explain than neurons.
  - fig-41 | Logit-Weight Scores, Features vs Neurons: Given only a written explanation of a unit, Claude predicts which unseen tokens that unit promotes with 0.74 mean accuracy for autoencoder features and 0.58 for MLP neurons, against a 0.5 chance baseline. The neuron distribution piles up on the chance line while the feature distribution spreads toward 1.0. The "failures" counts in the legend are parsing failures of the scoring harness, not low scores.
  - fig-42 | Interpretability Across the Activation Spectrum: Scoring each band of a unit's activation range separately, the paper's human annotator judged strong activations far more consistent with a feature's interpretation than weak ones. Autoencoder features average above the annotator's interpretability threshold only from roughly the 20% band upward, while MLP neurons stay far below it everywhere. So the monosemanticity claim is strongest exactly where features fire hardest, and thinnest at the bottom of the spectrum.
  - fig-68 | Sparsity Against Explained Behavior: Plotting how sparse each trained dictionary is against how much of the MLP layer's loss contribution it recovers turns hyperparameter choice into a visible tradeoff: a weaker sparsity penalty explains more of the model's behavior, but only by letting more features fire on every token. The four L1 coefficients sit as four separate vertical bands, so the penalty largely fixes the sparsity level, while widening the dictionary climbs the band by raising explained behavior at nearly constant sparsity.
  - fig-69 | Pearson vs Spearman Scoring Panel: The paper re-runs its automated interpretability scoring with Pearson correlation alongside the Spearman correlation used throughout the main text, and the two give visibly the same distributions and the same ordering: dictionary-learning features score well above transformer neurons, while features from a randomized model sit awkwardly high. This is a check that the headline gap does not depend on which correlation coefficient was chosen, not a new measurement.
  - fig-70 | The Randomized-Transformer Control: On the paper's automated activation score, features found in a random-weight transformer get a slightly higher median than the real features do. Splitting the randomized features on whether they are "single token" shows where that advantage comes from: the single-token half is trivially easy to score, and on everything else the real features win while the randomized ones sit about where polysemantic neurons sit. The panel is the paper's own warning that a good automated interpretability score, taken alone, is not evidence that a decomposition found real structure.
  - fig-71 | Importance-Weighted Interpretability Scores: Once the automated-interpretability scores are reweighted to what random text would have given, features still beat neurons (median 0.28 vs 0.04) but both distributions collapse toward zero. The paper's explanation is that a feature's true activations on random text are almost all zero — 88% on average, versus 54% for neurons — so the reweighted correlation mostly rewards predicting zero rather than predicting when the unit fires.
  - fig-72 | Explanation Length Distributions: A prompting bug sometimes let Claude's whole chain of thought stand in as a feature's explanation, producing explanations several hundred tokens long instead of a few dozen. This figure shows that the long tail appears in all three scored populations at similar rates — 19% for neurons, 15% for the randomized model, 13% for the A/1 features — and the appendix reports that splitting scores into long-explanation and short-explanation groups does not change them significantly. It is a caveat check the authors ran, not a result about features.
