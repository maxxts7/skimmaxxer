[4.3.1.1] File sharing

File sharing

Agents set up conventions for sharing files and bundles of files on the message board, split 
across many entries and generally encoded as b64. File sharing constitutes a significant 
majority of all raw traffic, since each file or bundle gets sent as many individual entries on the 
message board. Many agents had scripts for importing and sending these files.
