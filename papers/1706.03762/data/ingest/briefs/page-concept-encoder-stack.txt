NAME: Encoder stack

SUMMARY (already shown above your page as the lede - do not repeat it verbatim):
The Transformer's encoder: $N=6$ identical layers, each containing a multi-head self-attention sub-layer followed by a position-wise feed-forward sub-layer.

DRAFT EXPLANATION from the extraction stage (your page replaces this; keep what is right, go deeper):
The encoder is a stack of $N = 6$ identical layers. Each layer has two sub-layers: first a multi-head self-attention mechanism, then a position-wise fully connected feed-forward network. Around each sub-layer there is a residual connection followed by layer normalization, so each sub-layer's output is $\mathrm{LayerNorm}(x + \mathrm{Sublayer}(x))$. To make the residual additions line up, every sub-layer and the embedding layers all output vectors of the same dimension, $d_{model} = 512$.

THEME IT BELONGS TO: theme-the-shape-of-the-model | The shape of the model - The outline of the Transformer before any of the math. It keeps the familiar encoder-decoder frame: an encoder turns the input into representations, a decoder emits output tokens one at a time. Both are stacks of six identical layers, and every sub-layer inside a layer is wrapped in a residual connection followed by layer normalization. Read this to have a map before the parts are filled in.

PREREQUISITES:
  - multi-head-attention | Multi-head attention: Running $h$ attention functions in parallel on different learned linear projections of the queries, keys, and values, then concatenating and projecting the results.
  - self-attention | Self-attention (intra-attention): Attention where the queries, keys, and values all come from the same sequence, so every position can gather information from every other position in that sequence.
  - position-wise-feed-forward-network | Position-wise feed-forward network: A two-layer fully connected network applied to each sequence position independently and identically: expand to $d_{ff}=2048$, apply ReLU, project back to $d_{model}=512$.
  - residual-connection | Residual connection: A shortcut that adds a layer's input directly to its output, so the layer only has to learn a change (residual) on top of the identity.
  - layer-normalization | Layer normalization: A normalization step that rescales each position's activation vector to have a standard mean and variance, computed across the features of that single vector.
  - d-model | d_model = 512 (model dimension): The shared width of the model: every sub-layer and embedding layer outputs vectors of dimension $d_{model} = 512$.
