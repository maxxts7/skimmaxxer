NAME: Where attention is wired into the two stacks

THEME SUMMARY (shown above your page as the lede - do not repeat verbatim):
The same multi-head block appears in three places: encoder self-attention over the whole input, masked decoder self-attention, and encoder-decoder attention whose keys and values come from the encoder output. The mask is what separates the second use from the first — forbidden positions get minus infinity before the softmax, so they get zero weight, and that is what keeps generation auto-regressive. Around each attention or feed-forward sub-layer sits the same wrapper: a residual connection and layer normalization, which is where the cited layer-norm formula enters and why every sub-layer and embedding is forced to the single width d_model = 512. Equation (2) defines the other sub-layer, the per-position feed-forward network, and N = 6 fixes how many times the pair is stacked. Figure 1 shows the whole arrangement at once.

  e007 [load-bearing] causal-masking (Causal masking) --depends-on--> softmax (Softmax) | minus-infinity becomes zero weight: The mask sets forbidden scores to minus infinity before the softmax. It works only because exponentiating minus infinity gives zero, so those positions get no weight at all.
  e008 [load-bearing] masked-decoder-self-attention (Masked decoder self-attention) --depends-on--> auto-regressive-generation (Auto-regressive generation) | masking preserves auto-regression: The mask exists to stop leftward information flow so the auto-regressive property holds. Together with the one-position offset of the output embeddings, it ensures the prediction at position i uses only outputs before i.
  e009 [supporting] causal-masking (Causal masking) --depends-on--> scaled-dot-product-attention (Scaled dot-product attention) | implemented inside the attention function: Section 3.2.3 says masking is done inside scaled dot-product attention, on the input to the softmax. It is a stage of the existing attention block (the optional Mask box in Figure 2), not a separate layer.
  e010 [load-bearing] encoder-decoder-attention (Encoder-decoder attention) --depends-on--> encoder-stack (Encoder stack) | keys and values are encoder output: In this sub-layer the queries come from the previous decoder layer but the memory keys and values come from the encoder's output. There is nothing to attend over until the encoder stack has run.
  e012 [load-bearing] d-model (d_model = 512 (model dimension)) --depends-on--> residual-connection (Residual connection) | residuals force one shared width: Section 3.1 gives the reason directly: to facilitate the residual connections, all sub-layers and the embedding layers produce outputs of dimension 512. The uniform width is a consequence of adding inputs to outputs everywhere.
  e013 [load-bearing] sub-layer (Sub-layer) --depends-on--> layer-normalization (Layer normalization) | every sub-layer output is normalized: The wrapper around each sub-layer is LayerNorm(x + Sublayer(x)). The normalization is part of the sub-layer's definition, not an optional extra.
  e014 [load-bearing] layer-normalization (Layer normalization) --depends-on--> layer-normalization-statistics (Layer normalization statistics) | reuses the cited normalization formula: The paper uses layer normalization by citation and never writes the formula. The mean and standard deviation are computed across the hidden units of one position, which is what makes it work on variable-length sequences.
  e051 [supporting] encoder-decoder-architecture (Encoder-decoder architecture) --supported-by--> fig-1 (The two-stack data path (fig-1)) | draws both stacks and their link: Figure 1 puts the whole model in one picture: an N-layer encoder tower, an N-layer decoder tower, and the arrows carrying encoder output into each decoder layer's second attention sub-layer. It is a schematic, so it fixes wiring, not sizes.
  e060 [load-bearing] position-wise-feed-forward-network (Position-wise feed-forward network) --supported-by--> eq-ffn (The per-position feed-forward block (eq-ffn)) | defines the second sub-layer: Equation (2), max(0, xW1 + b1)W2 + b2, is the whole feed-forward sub-layer. It shows the network sees one position at a time: there is no mixing across positions here, so all cross-position work happens in the attention sub-layers.
  e063 [load-bearing] encoder-self-attention (Encoder self-attention) --instance-of--> multi-head-attention (Multi-head attention) | first of three attention uses: Section 3.2.3 lists three ways the Transformer uses multi-head attention. In the encoder, queries, keys and values all come from the previous encoder layer, so every position can attend to every position, with no mask.
  e064 [load-bearing] masked-decoder-self-attention (Masked decoder self-attention) --instance-of--> multi-head-attention (Multi-head attention) | second of three attention uses: The decoder runs the same multi-head attention over its own previous layer, but each position may only attend up to and including itself. The paper says this is needed to preserve the auto-regressive property.
  e065 [load-bearing] encoder-decoder-attention (Encoder-decoder attention) --instance-of--> multi-head-attention (Multi-head attention) | third of three attention uses: Here the queries come from the previous decoder layer and the keys and values come from the encoder output, so every decoder position can look at the whole input. The paper says this mimics the encoder-decoder attention of earlier sequence-to-sequence models.
  e068 [supporting] n-layers (N = 6 (number of layers)) --instance-of--> encoder-stack (Encoder stack) | fixes the stack depth at six: The encoder is described as a stack of N identical layers; the base model uses N = 6. The decoder uses the same depth.
  e069 [supporting] d-model (d_model = 512 (model dimension)) --instance-of--> transformer (The Transformer) | fixes the shared model width: Section 3.1 says every sub-layer and embedding layer outputs vectors of the same dimension so residual connections can be added, and sets that dimension to d_model = 512 in the base model.
  e086 [supporting] position-wise-feed-forward-network (Position-wise feed-forward network) --instance-of--> eq-ffn (The per-position feed-forward block (eq-ffn)) | defined by Equation (2): Equation (2) fixes the second sub-layer of every encoder and decoder layer as a two-layer MLP with a ReLU between, applied to each position separately with the same weights.
  e104 [supporting] masked-decoder-self-attention (Masked decoder self-attention) --contrasts-with--> encoder-self-attention (Encoder self-attention) | masked past vs full sequence: Same operation, different visibility: encoder self-attention lets every position attend to all positions, while decoder self-attention masks out future positions. The restriction is what keeps generation auto-regressive, so the decoder gives up the encoder's full context by design.
  e114 [supporting] layer-norm-vs-batch-norm (Contrast with batch normalization) --contrasts-with--> layer-normalization (Layer normalization) | across features vs across batch: From the Layer Normalization paper: batch normalization computes each neuron's statistics across the examples in a mini-batch, layer normalization across the features of a single example. The second does not depend on batch size or composition, which is why it fits per-position sequence models.
