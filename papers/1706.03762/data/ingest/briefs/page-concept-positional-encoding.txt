PAGE FOR CONCEPT: positional-encoding
NAME: Positional encoding

SUMMARY (already shown above your page as the lede - do not repeat it verbatim):
Vectors added to the input embeddings that inject information about each token's position, since the model itself has no recurrence or convolution to sense order.

DRAFT EXPLANATION from the extraction stage (your page replaces this; keep what is right, go deeper):
Self-attention is order-blind: shuffling the input positions would shuffle the outputs identically. Since the Transformer has no recurrence and no convolution, it must be given information about the relative or absolute position of tokens explicitly. The paper does this by adding 'positional encodings' to the input embeddings at the bottoms of both the encoder and decoder stacks. The encodings have the same dimension $d_{model}$ as the embeddings so the two can be summed elementwise. The encodings can be fixed functions or learned parameters; this paper uses fixed sinusoids but also tests the learned kind.

THEME IT BELONGS TO: theme-position-embeddings-and-feed-forward | Position, embeddings, and the feed-forward layer - The parts of a layer that act on each position on its own. Every layer's second sub-layer is a small two-layer network applied identically at every position, and the input and output embedding matrices are shared with the pre-softmax projection. Because there is no recurrence or convolution, nothing so far tells the model what order the tokens are in, so a fixed sinusoidal vector is added to each input embedding. These pieces complete the layer described in the previous themes.

SUB-CONCEPTS (these render as expandable sections BELOW your page - reference them, do not duplicate them):
  - sinusoidal-positional-encoding | Sinusoidal positional encoding: The paper's fixed positional encoding: each dimension is a sine or cosine of the position, at wavelengths forming a geometric progression from $2\pi$ to $10000 \cdot 2\pi$.
    - relative-position-linearity | Relative positions as linear functions: For any fixed offset $k$, the sinusoidal encoding of position $pos+k$ is a linear function of the encoding of position $pos$ — the hypothesized reason sinusoids help the model attend by relative position.
  - learned-positional-embedding | Learned positional embeddings: The alternative to sinusoids: a trainable vector per position, learned like any other parameter.
