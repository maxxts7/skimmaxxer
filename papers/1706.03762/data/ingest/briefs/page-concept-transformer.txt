NAME: The Transformer

SUMMARY (already shown above your page as the lede - do not repeat it verbatim):
The architecture this paper proposes: an encoder-decoder built entirely from stacked self-attention and position-wise feed-forward layers, with no recurrence and no convolutions.

DRAFT EXPLANATION from the extraction stage (your page replaces this; keep what is right, go deeper):
The Transformer keeps the standard encoder-decoder shape but replaces the recurrent (or convolutional) layers inside it with two building blocks: multi-head self-attention and point-wise (position-wise) fully connected layers. The encoder and decoder are each a stack of identical layers wrapped in residual connections and layer normalization. Because no step has to wait for the previous position's hidden state, much more of the computation can run in parallel, which the paper says cuts training time substantially. Because the model has no recurrence or convolution, word order is injected separately, via positional encodings added to the input embeddings. The paper reports 28.4 BLEU on WMT 2014 English-to-German (over 2 BLEU above prior results, including ensembles) and 41.8 BLEU on WMT 2014 English-to-French after 3.5 days on eight GPUs, and shows results on English constituency parsing as evidence the model generalizes beyond translation.

SUB-CONCEPTS (these render as expandable sections BELOW your page - reference them, do not duplicate them):
  - encoder-stack | Encoder stack: The Transformer's encoder: $N=6$ identical layers, each containing a multi-head self-attention sub-layer followed by a position-wise feed-forward sub-layer.
  - decoder-stack | Decoder stack: The Transformer's decoder: $N=6$ identical layers, each with masked self-attention, attention over the encoder output, and a feed-forward sub-layer.
  - sub-layer | Sub-layer: One of the components inside a Transformer layer — an attention mechanism or a feed-forward network — each wrapped in its own residual connection and layer normalization.
  - n-layers | N = 6 (number of layers): The number of identical layers stacked in each of the encoder and the decoder in the base model: six.
  - d-model | d_model = 512 (model dimension): The shared width of the model: every sub-layer and embedding layer outputs vectors of dimension $d_{model} = 512$.
  - position-wise-feed-forward-network | Position-wise feed-forward network: A two-layer fully connected network applied to each sequence position independently and identically: expand to $d_{ff}=2048$, apply ReLU, project back to $d_{model}=512$.
    - d-ff | d_ff = 2048 (feed-forward inner dimension): The width of the hidden layer inside the position-wise feed-forward network: 2048, four times $d_{model}$.
    - relu | ReLU activation: The rectified linear unit, $\max(0, x)$: a standard nonlinearity that zeroes out negative values.
  - token-embeddings | Token embeddings: Learned lookup tables that convert input and output tokens into $d_{model}$-dimensional vectors.
  - embedding-softmax-weight-sharing | Embedding and softmax weight sharing: The two token embedding layers and the pre-softmax output projection all share a single weight matrix.
    - sqrt-dmodel-embedding-multiplier | sqrt(d_model) embedding multiplier: In the embedding layers, the shared weights are multiplied by $\sqrt{d_{model}}$.
  - positional-encoding | Positional encoding: Vectors added to the input embeddings that inject information about each token's position, since the model itself has no recurrence or convolution to sense order.
    - sinusoidal-positional-encoding | Sinusoidal positional encoding: The paper's fixed positional encoding: each dimension is a sine or cosine of the position, at wavelengths forming a geometric progression from $2\pi$ to $10000 \cdot 2\pi$.
      - relative-position-linearity | Relative positions as linear functions: For any fixed offset $k$, the sinusoidal encoding of position $pos+k$ is a linear function of the encoding of position $pos$ — the hypothesized reason sinusoids help the model attend by relative position.
    - learned-positional-embedding | Learned positional embeddings: The alternative to sinusoids: a trainable vector per position, learned like any other parameter.

PREREQUISITES:
  - sequence-transduction | Sequence transduction: The general task of converting one sequence of symbols into another sequence, such as translating a German sentence into English.
  - encoder-decoder-architecture | Encoder-decoder architecture: A two-part model design: an encoder turns the input sequence into continuous representations, and a decoder generates the output sequence from them, one symbol at a time.
  - attention-mechanism | Attention mechanism (query, key, value): A function that maps a query vector and a set of key-value vector pairs to an output: a weighted sum of the values, with weights set by how well the query matches each key.
  - self-attention | Self-attention (intra-attention): Attention where the queries, keys, and values all come from the same sequence, so every position can gather information from every other position in that sequence.
  - bleu | BLEU score: The standard automatic metric for translation quality: n-gram overlap precision against reference translations with a penalty for overly short outputs. Higher is better.
