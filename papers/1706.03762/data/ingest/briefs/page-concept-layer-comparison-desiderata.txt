DRAFT EXPLANATION from the extraction stage (your page replaces this; keep what is right, go deeper):
To motivate self-attention, the paper compares layer types on three axes. First, total computational complexity per layer — how much arithmetic one layer costs. Second, parallelizability, measured as the minimum number of operations that must run one after another. Third, the maximum path length between any two input and output positions, which the paper links to how easily the network learns long-range dependencies. Table 1 summarizes the comparison; the headline is that self-attention wins on sequential operations ($O(1)$ vs $O(n)$ for recurrence) and path length, and wins on complexity whenever sequence length $n$ is smaller than representation dimension $d$.
