CONCEPT EXPLANATIONS (12)

--- CONCEPT id=lsr-as-two-cross-entropy-losses ---
NAME: LSR as a pair of cross-entropy losses
OWNER: 1512.00567
SUMMARY (leave alone): Because cross entropy is linear in the target, smoothing splits the loss into the ordinary one-hot cross entropy plus a term that pulls the predicted distribution toward the prior $u$. The second term carries relative weight $\epsilon/(1-\epsilon)$.

EXPLANATION:
Substituting $q' = (1-\epsilon)q + \epsilon u$ into the cross entropy and using linearity in the target gives $$H(q',p) = -\sum_{k=1}^{K} q'(k)\log p(k) = (1-\epsilon)H(q,p) + \epsilon H(u,p).$$ So LSR is equivalent to replacing the single loss $H(q,p)$ with a pair of losses: the usual term on the true label, and $H(u,p)$, which penalizes deviation of the predicted distribution $p$ from the fixed prior $u$. Their relative weight is $\epsilon/(1-\epsilon)$. That second term can equivalently be read as a KL divergence, since $H(u,p) = D_{KL}(u\|p) + H(u)$ and $H(u)$ is a constant that does not affect gradients. When $u$ is uniform, $H(u,p)$ measures how far $p$ is from uniform; the paper notes negative entropy $-H(p)$ would measure something similar but not equivalent, and says it did not try that. This decomposition is the cheapest way to implement LSR: keep the existing cross-entropy code and add the prior term, or simply build the smoothed target vector $q'$ and feed it to the same loss.

--- CONCEPT id=overconfidence-and-bounded-logit-gradient ---
NAME: Why one-hot targets encourage overconfidence
OWNER: 1512.00567
SUMMARY (leave alone): A one-hot target is only approached as the correct logit grows far larger than the rest, which the paper argues causes overfitting and, given the bounded logit gradient, reduces the model's ability to adapt.

EXPLANATION:
With $q(k) = \delta_{k,y}$, the cross-entropy minimum is not attainable at finite logits; it is only approached as $z_y \gg z_k$ for all $k \neq y$. The paper flags two consequences. First, if the model learns to put full probability on the ground-truth label of every training example, there is no guarantee that behavior generalizes. Second, training keeps pushing the gap between the largest logit and the others wider, and because the gradient with respect to the logits, $\partial \ell / \partial z_k = p(k) - q(k)$, is bounded between $-1$ and $1$, the paper argues this reduces the model's ability to adapt. It describes the mechanism intuitively as the model becoming too confident about its predictions. LSR targets exactly this: since every $q'(k)$ has a positive lower bound, a prediction that sends one probability toward 1 and the rest toward 0 incurs a large cross entropy against $q'$, so the largest logit is prevented from running far ahead of the others. The paper is explicit that this is a trade: it says the method is not what you want if the goal is to maximize the log-likelihood of the training labels, but that it regularizes the model and makes it more adaptable.

--- CONCEPT id=smoothing-parameter-epsilon ---
NAME: Choosing $\epsilon$ and the prior $u$
OWNER: 1512.00567
SUMMARY (leave alone): LSR has two knobs: the smoothing parameter $\epsilon$ and the fixed distribution $u$. The paper's reported setting is $\epsilon = 0.1$ with uniform $u(k)=1/K$ over $K = 1000$ ImageNet classes.

EXPLANATION:
$\epsilon$ controls how much target mass leaves the correct label; $u$ decides where it goes. The paper proposes using the prior distribution over labels as $u$, and in practice uses the uniform distribution, so the whole scheme reduces to the single hyperparameter $\epsilon$ once $K$ is fixed. Its ImageNet setting is $K = 1000$, $u(k) = 1/1000$, $\epsilon = 0.1$, which puts $0.9 + 0.0001$ on the true class and $0.0001$ on each other class. Reported effect: a consistent improvement of about 0.2% absolute on both top-1 and top-5 error for ILSVRC 2012, listed as one of the cumulative ingredients in the paper's ablation table. Note that with a smoothed target the training loss has a floor: the minimum of $-\sum_k q'(k)\log p(k)$ is the entropy $H(q')$, reached at $p = q'$, so the loss value is no longer comparable to an unsmoothed run and the model is calibrated toward $q'$ rather than toward the true labels. A model trained this way is deliberately less confident, which can cost likelihood-style metrics even where it helps accuracy — the paper frames the method as trading training-label log-likelihood for regularization.

--- CONCEPT id=wordpiece-model ---
NAME: Wordpiece model (sub-word vocabulary)
OWNER: 1609.08144
SUMMARY (leave alone): A data-driven sub-word vocabulary: words are split into a fixed set of common sub-word units, so any string can be encoded with no out-of-vocabulary tokens. The segmentation is deterministic and losslessly reversible.

EXPLANATION:
A wordpiece vocabulary is a fixed set of $D$ sub-word strings chosen from a training corpus. Given a target size $D$, the vocabulary is selected greedily to maximize the language-model likelihood of the training data under the evolving vocabulary; equivalently, it seeks the $D$ pieces that segment the corpus into the fewest total tokens. The seed vocabulary is the set of basic characters, capped at a manageable number (roughly 500 for Western languages, more for Asian ones) with the remaining rare characters mapped to a single unknown-character symbol so they do not pollute the vocabulary. Word boundaries are made recoverable by prepending a special marker character (written here as `_`) to the start of each word before training, and only at the start, not at both ends; the original word sequence is therefore reconstructed from the piece sequence without ambiguity. Example: `Jet makers feud over seat width` segments as `_J et _makers _fe ud _over _seat _width`, where common words stay whole and rare ones split. At inference the model emits a wordpiece sequence, which is then joined back into words as a post-processing step. Vocabularies between 8k and 32k pieces are reported to give a good trade-off between accuracy and decoding speed. For translation, a single shared vocabulary is trained over both source and target text, so an identical string is segmented identically on both sides, which makes copying names and numbers across languages easier to learn. The scheme sits between character models (flexible but long sequences, more compute) and word models (short sequences but a closed vocabulary).

--- CONCEPT id=length-normalization-penalty ---
NAME: Length normalization penalty lp(Y)
OWNER: 1609.08144
SUMMARY (leave alone): A divisor applied to a hypothesis's log-probability during beam search so that longer and shorter candidates can be compared fairly. It is controlled by a single exponent alpha.

EXPLANATION:
Beam search that ranks hypotheses by raw $\log P(Y\mid X)$ favors short outputs, because each decoding step adds a negative log-probability, so longer sequences score lower simply for being longer. The fix is to divide the log-probability by a function of the length. Dividing by the length itself over-corrects; the refinement is to divide by $|Y|^{\alpha}$ with $0 < \alpha < 1$. The form actually used is a shifted, normalized version: $$lp(Y) = \frac{(5 + |Y|)^{\alpha}}{(5 + 1)^{\alpha}}$$ where $|Y|$ is the number of target tokens in the hypothesis. The constant 5 softens the penalty for very short hypotheses, and dividing by $(5+1)^{\alpha}$ makes $lp(Y)=1$ at length 1, so the scale of scores stays comparable across settings of $\alpha$. The normalized score is $\log(P(Y\mid X))/lp(Y)$; setting $\alpha = 0$ gives $lp(Y)=1$ and recovers plain probability-ranked beam search. Alpha is tuned on a development set: values in $[0.6, 0.7]$ are reported as usually best when length normalization is used alone, while a sweep run jointly with a coverage penalty found a broad plateau of near-best scores, with the reported best at $\alpha = 0.2, \beta = 0.2$ (+1.1 BLEU over $\alpha=\beta=0$ on WMT'14 En→Fr dev). The penalty affects ranking only; it does not change the model or the per-step distribution.

--- CONCEPT id=coverage-penalty ---
NAME: Coverage penalty cp(X; Y)
OWNER: 1609.08144
SUMMARY (leave alone): An extra term in the beam-search score that rewards hypotheses whose attention has spread over the whole source sentence. It is controlled by a weight beta and is optional.

EXPLANATION:
The coverage penalty is added to the length-normalized score to discourage under-translation, where the decoder ignores part of the input. Let $p_{i,j}$ be the attention probability the $j$-th target token places on the $i$-th source token, so that the attention weights sum to 1 over the source for each target step. Total attention received by source token $i$ is $\sum_{j=1}^{|Y|} p_{i,j}$, and the penalty is $$cp(X; Y) = \beta \sum_{i=1}^{|X|} \log\left(\min\left(\sum_{j=1}^{|Y|} p_{i,j},\; 1.0\right)\right).$$ The $\min$ with 1.0 caps the credit each source token can earn, so attending to one token repeatedly does not help; the $\log$ makes source tokens that receive almost no attention very costly. The complete ranking score is $$s(Y, X) = \frac{\log(P(Y\mid X))}{lp(Y)} + cp(X; Y),$$ with $lp$ the length-normalization divisor. Setting $\alpha = 0$ and $\beta = 0$ reduces this to pure probability-based beam search. Because the term reads the attention matrix, it applies only to architectures that expose one, and a decoder can use the length normalization without it by setting $\beta = 0$. The reported effect is smaller for models already fine-tuned with a sequence-level objective, since those learn to cover the source anyway.

--- CONCEPT id=beam-search-pruning-and-termination ---
NAME: Beam search pruning and early termination
OWNER: 1609.08144
SUMMARY (leave alone): Beyond keeping a fixed number of hypotheses, the decoder prunes candidates that fall a fixed margin below the current best, both per-step and among finished hypotheses. This is what makes search stop early instead of running to a fixed maximum length.

EXPLANATION:
The decoder keeps a beam of typically 8-12 hypotheses, with 4 or 2 reported to cost only slightly in quality. Two additional threshold prunes are applied, both using a margin in log-score units (confusingly also called `beamsize`, typically $3.0$, and distinct from the number of hypotheses). First, per step: only tokens whose local score is within the margin of the best token at that step are expanded. Second, across finished hypotheses: once a normalized best score exists under the ranking function, any hypothesis more than the margin below that best normalized score is dropped. The second prune applies only to complete hypotheses, because the normalized score involves the length penalty and is well defined only when a hypothesis ends. Its practical effect is early termination: as soon as one sufficiently good complete hypothesis exists, nearly all remaining partial hypotheses fall out of the beam and search stops, rather than continuing to a fixed cap. Without this pruning the fallback is to decode to a predetermined maximum output length, set to twice the source length; the pruning is reported to speed up CPU search by 30-40% versus that fallback. When many sentences (typically up to 35, batched by similar length) are decoded in parallel, the batch finishes only when every sentence's hypotheses are out of beam, which the paper reports costs little in practice.

--- CONCEPT id=input-and-output-embeddings ---
NAME: Input and Output Embeddings
OWNER: 1608.05859
SUMMARY (leave alone): A word-level neural language model holds two matrices of the same shape: the input embedding that maps a token id to a vector, and the pre-softmax projection matrix that maps a hidden state to one score per vocabulary word. This paper names the second one the output embedding and argues it is a word embedding in its own right.

EXPLANATION:
Take a vocabulary of size $C$ and a hidden width $H$. The input word is a one-hot vector $c \in \mathbb{R}^{C}$ and the input embedding $U \in \mathbb{R}^{C \times H}$ turns it into the dense vector $U^{\top} c$, i.e. row $U_k$ is the vector for word $k$. The network computes some activation $h_2 \in \mathbb{R}^{H}$ from that, and a second matrix $V \in \mathbb{R}^{C \times H}$ produces the logits $h_3 = V h_2$, which the softmax turns into next-word probabilities. So $V_k$, row $k$ of the output embedding, is the vector whose inner product with the hidden state gives word $k$'s score: $p_t(o_t \mid i_{1:t}) = \frac{\exp(V_{o_t}^{\top} h_2^{(t)})}{\sum_{x=1}^{C} \exp(V_x^{\top} h_2^{(t)})}$. Both matrices are $C \times H$, so they are interchangeable in shape. The paper's claim is that both encode word similarity, for different reasons: $U$ should give similar rows to synonyms so the network reacts to them similarly, while $V$ should give similar rows to interchangeable words so their scores come out similar. Standard practice at the time was to treat only $U$ as "the" word embedding and discard $V$; the paper measures $V$ on word-similarity benchmarks and reports it is roughly as good as $U$ in word2vec skip-gram and better than $U$ in recurrent language models.

--- CONCEPT id=weight-tying ---
NAME: Weight Tying (U = V = S)
OWNER: 1608.05859
SUMMARY (leave alone): Weight tying replaces the separate input embedding and pre-softmax projection with one shared matrix S used in both roles. It cuts the parameter count by one C-by-H matrix and, in the paper's language-model experiments, lowers perplexity.

EXPLANATION:
Tying means enforcing $U = V = S$ with $S \in \mathbb{R}^{C \times H}$: the same row $S_k$ both embeds word $k$ on input and scores word $k$ before the softmax, so the logit for word $k$ becomes $S_k^{\top} h_2$. The constraint requires the embedding width and the pre-softmax input width to match; if they differ, an extra projection is needed. There is no extra loss term or stop-gradient involved. Gradients from both roles land on the same matrix and are simply summed, so one shared matrix is trained by two different signals at once. The parameter saving is exactly $C \times H$ weights, which dominates model size when the vocabulary is large: the paper's large PTB language model drops from 66M to 51M parameters, and a decoder-tied translation model from 168M to 122M. In the paper's language-model results, training perplexity rises while validation and test perplexity fall, which it reads as less overfitting from the reduced parameter count. The paper also reports a limit: tying is harmful in word2vec skip-gram, where the hidden layer is the identity, because if $p_t(i_t \mid i_{1:t})$ is near zero the norm of the embedding of $i_t$ is pushed toward zero as well; the recurrent layers in a language model decouple the two roles enough that this does not apply.

--- CONCEPT id=tied-embedding-update-dynamics ---
NAME: Why Tying Helps: Update Dynamics
OWNER: 1608.05859
SUMMARY (leave alone): In an untied model, only the row of the current input word gets an input-embedding gradient each step, while every row of the output embedding gets one. The paper shows that in the tied model each row's update is the sum of the two, and that the result behaves mostly like the output embedding.

EXPLANATION:
For the cross-entropy loss $L_t = -\log p_t(o_t \mid i_{1:t})$ at step $t$ with input history $i_{1:t}$ and target $o_t$, the input-embedding gradient is nonzero only for the current input word: $\frac{\partial L_t}{\partial U_k} = \left( \sum_{x=1}^{C} p_t(x \mid i_{1:t}) V_x^{\top} - V_{o_t}^{\top} \right) \frac{\partial h_2^{(t)}}{\partial U_{i_t}}$ when $k = i_t$, and $0$ otherwise. The output-embedding gradient touches every row: $\frac{\partial L_t}{\partial V_k} = (p_t(o_t \mid i_{1:t}) - 1)\, h_2^{(t)}$ when $k = o_t$, and $p_t(k \mid i_{1:t})\, h_2^{(t)}$ otherwise. So rare words' input rows are updated only on the few steps where they appear, while their output rows are updated at every step. Under tying, row $S_k$ receives the sum of both terms. For $k \neq i_t$ only the output term is present, so the update matches the untied output-embedding update with $U$ and $V$ replaced by $S$. For $k = i_t$ the output term scales with $p_t(i_t \mid i_{1:t})$, the probability that the current input word is also the target; that is near zero because words seldom repeat back to back, so the input term dominates. The paper's conclusion is that every row of $S$ is updated every step and that the tied embedding ends up closer to the untied output embedding than to the untied input embedding, which it corroborates with rank correlations of pairwise word distances (Out-vs-Tied $\rho$ up to 0.77, In-vs-Tied 0.31-0.45).

--- CONCEPT id=three-way-weight-tying ---
NAME: Three-Way Weight Tying
OWNER: 1608.05859
SUMMARY (leave alone): In an encoder-decoder translation model, three-way weight tying shares one matrix across the encoder input embedding, the decoder input embedding, and the decoder pre-softmax projection. It requires a single joint vocabulary built over both languages.

EXPLANATION:
A translation decoder scores target words as $p_t(o_t \mid i_{1:t}, r) = \frac{\exp(V_{o_t}^{\top} G^{(t)})}{\sum_{x=1}^{C_t} \exp(V_x^{\top} G^{(t)})}$, where $G^{(t)}$ is the decoder state, $U, V \in \mathbb{R}^{C_t \times H}$ are the decoder input and output embeddings, and $W \in \mathbb{R}^{C_s \times H}$ is the encoder input embedding, with $C_s$ and $C_t$ the source and target vocabulary sizes. Decoder-only tying sets $U = V$. Three-way weight tying (TWWT) additionally sets $W$ to the same matrix, so source and target tokens are embedded in one shared space and one matrix serves all three roles. This only makes sense if the two vocabularies overlap, so the model is trained on a single joint vocabulary that is the union of the source and target vocabularies. The paper obtains that overlap with subword segmentation: learning byte-pair-encoding merges over the union of both languages' text (89500 merge operations in its experiments) leaves most subwords shared between the two languages, 85K shared out of about 94K for English-French and 80K out of about 94K for English-German. Reported effect: the three-way tied models have about 52% fewer parameters than the untied baselines (168M to 80M for English-French, 165M to 79M for English-German) with BLEU scores within noise of the baselines.

--- CONCEPT id=parse-tree-linearization ---
NAME: Parse Tree Linearization
OWNER: 1412.7449
SUMMARY (leave alone): A constituency parse tree is turned into a flat token sequence by a depth-first traversal that emits an opening bracket-plus-label when entering a node and a matching labeled closing bracket when leaving it. This makes parsing a plain sequence-to-sequence task: input is the sentence, output is the linearized tree.

EXPLANATION:
Constituency parsing normally outputs a tree; sequence models output a string. The linearization walks the tree depth-first (left to right) and writes, for each nonterminal node, an opening symbol $(X$ before its children and a closing symbol $)X$ after them, with terminals written in place. For the sentence "John has a dog ." with tree S -> NP(NNP) VP(VBZ NP(DT NN)) . the output string is $(S\;(NP\;NNP\;)NP\;(VP\;VBZ\;(NP\;DT\;NN\;)NP\;)VP\;.\;)S$. The mapping is invertible: because closing brackets carry their label and the traversal order is fixed, a well-formed output string reconstructs exactly one tree. Two preprocessing choices go with it. Part-of-speech tags are normalized to the single symbol XX, since POS tags are not scored by the standard constituency F1 metric; this reported about +1 F1. Trees are not binarized and unary chains get no special treatment. The output vocabulary stays tiny — 128 symbols in the reported setup, against a 90K input word vocabulary with a single UNK for out-of-vocabulary words. Nothing constrains the decoder to emit balanced brackets, so a small fraction of outputs are malformed (1.5% of development sentences for a model trained on 40K sentences, 0.8% for the large-corpus model); the fix used is to append or prepend brackets until the string balances. Failures concentrated on sentences that did not end in proper punctuation.
