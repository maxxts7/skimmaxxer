NAME: Masked Self-Attention

SUMMARY (already shown above your page as the lede - do not repeat it verbatim):
Self-attention restricted so each position attends only to itself and earlier positions, never to later ones.

DRAFT EXPLANATION from the extraction stage (your page replaces this; keep what is right, go deeper):
Plain self-attention lets every position attend to every other, including positions to its right. In a language model that would be fatal: the model would see token $u_i$ while being asked to predict $u_i$, and $L_1$ would be trivial to maximize.

The fix is a mask. Before the attention softmax, the scores for all positions to the right of the current one are driven to $-\infty$, so after normalization their weights are zero.

Each position then summarizes only $u_{i-k},\dots,u_i$, which is exactly the conditioning set written down in $L_1$.

The practical payoff is throughput. One forward pass over a 512-token sequence yields a valid next-token prediction at every position at once, rather than one prediction per pass.

All twelve attention heads at all twelve layers are masked this way.

The mask stays in place during fine-tuning too. That is why a classification input must be one ordered sequence, and why the label is read off the final token rather than pooled across positions.

THEME IT BELONGS TO: theme-stage-one-next-token-prediction | Stage One: Predicting the Next Token - Stage one trains on a single loss: the log-probability the model assigns each token given a window of preceding tokens, summed over the corpus. The window here is 512 contiguous tokens, which is what lets a prediction condition on material several sentences back. The network is a stack of transformer blocks used as a decoder alone, with self-attention masked so each position sees only itself and its past, learned position vectors rather than fixed sinusoids, and an output layer that reuses the token embedding matrix transposed. This chapter also fixes the exact sizes trained, and closes with the claim the paper makes about what such training leaves behind.
