NAME: Language Modelling Objective $L_1$

SUMMARY (already shown above your page as the lede - do not repeat it verbatim):
The pre-training loss $L_1(U)=\sum_i \log P(u_i \mid u_{i-k},\dots,u_{i-1};\Theta)$: maximize the log-probability the model gives each token given the tokens before it.

DRAFT EXPLANATION from the extraction stage (your page replaces this; keep what is right, go deeper):
Take a position $i$ in the corpus. The model reads the $k$ tokens before it and produces a distribution over the vocabulary for position $i$.

The objective picks out the log-probability that distribution assigned to the token that actually appeared.

Those log-probabilities are summed over every position in the corpus, and the sum is maximized by stochastic gradient descent over the parameters $\Theta$.

Only preceding tokens condition each prediction. The objective is strictly left-to-right, which is what makes masked self-attention necessary in the architecture.

Because no annotation is needed to build an example, every token of the corpus is a training case.

The paper labels this term $L_1$ and reuses the label in Section 3.2, where it returns as an auxiliary term during fine-tuning.

THEME IT BELONGS TO: theme-stage-one-next-token-prediction | Stage One: Predicting the Next Token - Stage one trains on a single loss: the log-probability the model assigns each token given a window of preceding tokens, summed over the corpus. The window here is 512 contiguous tokens, which is what lets a prediction condition on material several sentences back. The network is a stack of transformer blocks used as a decoder alone, with self-attention masked so each position sees only itself and its past, learned position vectors rather than fixed sinusoids, and an output layer that reuses the token embedding matrix transposed. This chapter also fixes the exact sizes trained, and closes with the claim the paper makes about what such training leaves behind.

  - fig-1 | One Stack, Four Input Shapes: The figure shows that a single decoder-only transformer, pre-trained once, serves every task in the paper: the left panel draws the block that is repeated twelve times and the two heads that sit on it, and the right panel shows that adapting to a new task means rewriting its input as one token sequence rather than redesigning the network. The only task-specific machinery is the added linear layer and the special tokens marking where the parts of an input begin and end.
  - eq-lm-objective | The Pre-Training Likelihood $L_1$: This is the entire training signal for stage one: over a corpus of unlabelled tokens, sum the log-probability the network assigns to each token given the $k$ tokens immediately before it, and adjust the network's parameters $\Theta$ to make that sum as large as possible. No labels, no task, and one training term per token position.
  - eq-decoder-stack | The Decoder Stack, Input to Output Distribution: Equation 2 spells out the whole pre-training network in three lines: embed the context tokens and their positions, push the result through $n$ identical transformer blocks, then project the top layer back through the transposed token embedding matrix and softmax it into a distribution over the next token. The same matrix $W_e$ does the work at both ends, so no separate output vocabulary matrix is introduced.
  - eq-supervised-objective | Supervised Fine-Tuning Objective $L_2$: Equation 4 is the loss used in the second training stage: over a target task's labelled dataset $\mathcal{C}$, sum the log-probability the model assigns to each instance's correct label. It is ordinary maximum-likelihood classification training, written so that the only thing separating one task from another is which labelled set $\mathcal{C}$ you plug in.
  - eq-combined-objective | The Combined Fine-Tuning Objective: During fine-tuning the paper does not drop the language modelling loss; it keeps optimizing it alongside the classification loss, scaled by a weight $\lambda$, and computes it on the labelled task data rather than on the pre-training corpus. The paper reports this helped by improving generalization and speeding convergence, and its own ablation later qualifies that: the gain shows up on larger datasets, not on smaller ones.
