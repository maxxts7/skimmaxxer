NAME: The Next-Token Machine

THEME SUMMARY (shown above your page as the lede - do not repeat verbatim):
Stage one is one loss and one network, and the paper writes both down. The loss, $L_1$ in Equation 1, is the summed log-probability the model assigns to each token given the $k$ tokens before it, which is ordinary maximum-likelihood fitting applied to text; the paper treats picking this objective as a choice among candidates, since which unsupervised objective transfers best was one of the open questions it names. The network is a stack of transformer blocks used as a decoder only, with the encoder half of the original encoder-decoder design dropped, and its self-attention masked so that each position sees only itself and earlier positions — that masking is what makes next-token prediction a well-posed target instead of a lookup. Equation 2 gives the rest in three lines: the layer-zero input is token embeddings plus a trained table of position embeddings, one vector per slot; $n$ identical blocks run over it; the top states are multiplied by the transpose of the same token embedding matrix and softmaxed into a distribution over the vocabulary, so input and output layers share parameters. The concrete model fills in the sizes — twelve heads splitting 768 dimensions into 64 each, a feed-forward sublayer widening to 3072 and back, weights drawn from $\mathcal{N}(0, 0.02)$ on the argument that layer normalization throughout makes a plain initialization enough, and dropout at 0.1 on residual branches, embeddings and attention.

The 512-token window is therefore a size in the parameter table, not a setting that can be raised at test time.

Common words survive as single rows and rare words are split into several. Because the output softmax reuses $W_e^T$, the distribution the model predicts is a distribution over those same subword units.
